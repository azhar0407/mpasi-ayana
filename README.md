# MPASI Ayana

Aplikasi web mobile-first berisi 105 resep MPASI Baby-Led Weaning (BLW), jadwal menu 30 hari, panduan singkat, dan buku digital untuk Ayana.

## Fitur

- Pencarian dan filter 105 resep
- Detail bahan, langkah, gizi, dan penyajian
- Jadwal menu 30 hari
- Panduan MPASI dan BLW
- Buku digital PDF
- Tampilan responsif dan dukungan layar penuh iOS

## Menjalankan lokal

Persyaratan: Node.js 20 atau lebih baru.

```bash
npm ci
npm run dev
```

## Verifikasi

```bash
npm run lint
npm run build
```

## Teknologi

React, Vite, Tailwind CSS, dan Lucide React.

> Informasi dalam aplikasi bersifat panduan umum, bukan pengganti konsultasi dengan dokter anak atau ahli gizi.
